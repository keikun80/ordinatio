# Phase 3 FinOps · AI거버넌스 정합성 수정 및 검증

- 2026-11-28: 테넌트 목록·상세 및 가상키 목록의 당월 지출/토큰 조회를 FinOps와 동일한 일별 원장 집계로 변경했다. 캐시 드리프트와 월 경계에 따른 화면 차이를 방지한다. 가상키 지출은 해당 키에 귀속된 원장 합계이며, 부서 지출은 부서 단위 조정분을 포함한다.
