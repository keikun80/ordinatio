# Ordinatio Standalone Appliance (Air-Gapped Edition)

고객사 온프레미스 폐쇄망 환경을 위한 독립형 자율 운영 AI 오케스트레이터 어플라이언스 패키지입니다.
외부 인터넷 연결이 전혀 없는 환경에서도 5대 코어 서비스가 100% 로컬에서 동작합니다.

---

## 🚀 1분 퀵스타트 (Quick Start)

### 1. 사전 요구사항
- **OS**: Linux (RHEL 8/9, Rocky, Ubuntu 20.04+) 또는 macOS
- **엔진**: Docker 20.10+ 및 Docker Compose v2 (docker compose plugin)
- **외부 인터넷 연결**: 불필요 (100% 에어갭 오프라인 자립)

### 2. 기동 및 실행
```bash
# 원스톱 기동 (이미지 자동 로드, .env 자동 구성, 헬스체크 및 관리자 계정 생성)
make up
```

기동이 완료되면 터미널에 표시되는 URL로 브라우저에서 접속합니다:
- **웹 관리 콘솔**: `http://<서버IP>:5173`
- **L7 AI Gateway 엔드포인트**: `http://<서버IP>:8080/v1`
- **초기 관리자 계정**: `admin` / `.env` 파일에 기록된 비밀번호 (기본: `admin1234!`)

---

## 🛠️ 주요 운영 관리 명령어

| 명령어 | 설명 |
|---|---|
| `make up` | 오프라인 이미지 자동 로드 및 어플라이언스 전체 서비스 기동 |
| `make down` | 전체 서비스 안전 중지 (데이터 볼륨 보존) |
| `make restart` | 전체 서비스 재기동 |
| `make status` | 5대 서비스 컨테이너 헬스체크 및 포트 상태 확인 |
| `make logs` | 서비스 실시간 통합 로그 확인 (`Ctrl+C`로 종료) |
| `make init-admin` | 관리자 계정 추가 생성 또는 비밀번호 재설정 |
| `make backup` | 메타스토어 데이터베이스 즉시 백업 (`backups/` 디렉터리) |

---

## 🔒 보안 아키텍처 원칙
- **호스트 루프백 격리**: PostgreSQL(5432)과 Redis(6379), Backend(8000)는 외부 네트워크에 노출되지 않고 `127.0.0.1` 루프백으로 바인딩되어 내부 보호됩니다.
- **단일 진입점**: 모든 외부 AI 추론 트래픽은 L7 Envoy AI Gateway(8080)를 통해서만 진입합니다.
- **불변 이미지**: 소스 코드 마운트 없이 패키지 내부에 번들링된 불변 컨테이너 이미지로 구동됩니다.
